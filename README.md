# 支点学社网站：GitHub Pages 轻量发布副本

此目录用于临时发布 GitHub Pages。原始完整网站文件仍保留在相邻的 `0_pivot_website` 目录中。

为满足 GitHub Pages 的体积和文件限制，本副本没有包含：

- 两个大型 MP4 视频；
- 历年社刊大 PDF；
- ZIP、PSB 等编辑源文件；
- 原项目的 Git LFS 配置。

已保留首页、各 HTML 页面、CSS、JavaScript、网页图片、赛题资料和两份活动 PDF。

## 发布设置

在 GitHub 仓库的 `Settings > Pages` 中选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

## 暂不可用的内容

“社刊”页面中的历年期刊下载链接，以及“活动”页面中的两个视频链接，在临时托管期间没有对应文件。2025 年大文大理决赛页面原本引用的 `2025大文大理2025决赛.pdf` 在完整源目录中也不存在，因此该组链接仍会显示 404；源目录中只有名称不同的 PPTX 文件。
